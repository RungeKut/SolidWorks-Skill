# Рабочий цикл swkit

## Подключение

```python
import sys
sys.path.insert(0, r"<корень набора>")   # папка SKILL.md; в скриптах — от __file__
import swkit as sw

sw.utf8_console()          # иначе print с кириллицей упадёт (30-07, п. 6)
app = sw.app()             # подключение к ЗАПУЩЕННОМУ SolidWorks
```

SolidWorks должен быть запущен **до** подключения: `sw.app()` цепляется к
работающему экземпляру, а не ждёт его. Не запущен — поднять и дождаться
регистрации в COM циклом
([40-01](../40_СРЕДА/40-01_установка_и_MCP.md), «Запуск SolidWorks»):
пока приложение не в ROT, `sw.app()` поднимет **второй** экземпляр. Окно
после такого старта невидимо, `sw.app()` показывает его сам.

## Минимальный цикл

```python
doc = sw.new_part(app)

with sw.Sketch(doc, sw.TOP) as sk:        # 0 Спереди, 1 Сверху, 2 Справа
    sk.rect(0, 0, 2000, 1000)             # ВСЕГДА миллиметры
sw.extrude(doc, sk.feature, 200)

with sw.Sketch(doc, sw.TOP) as sk2:
    sk2.rect(500, 300, 900, 700)
sw.cut(doc, sk2.feature, end=sw.THROUGH_ALL)

sw.check_part(doc, "Плита",
              expect_volume_mm3=2000*1000*200 - 400*400*200,
              expect_box_mm=[2000, 200, 1000])
sw.save_as(doc, r"C:\проект\Плита.SLDPRT")
sw.shot(doc, r"C:\проект\вид.png", view="iso")
sw.close(app, doc)
```

## Шесть правил, нарушение которых стоит часа

1. **Миллиметры и градусы** на входе `swkit`. API работает в метрах и
   радианах, перевод — внутри библиотеки. При прямом вызове API переводить
   самим.
2. **Плоскости — по индексу, не по имени.** `sw.TOP`, а не `"Сверху"`:
   имена зависят от языка интерфейса и установки — на машине с 2021 они
   английские при русской локализации
   ([40-03](../40_СРЕДА/40-03_версии_SolidWorks_и_машины.md)).
3. **Направление выреза обратное вытяжке.** У `sw.cut` умолчание
   `reverse=True`, у `sw.extrude` — `False`. Это не опечатка
   ([30-02](../30_ГРАБЛИ/30-02_направление_выреза.md)).
4. **Проверять результат числом И глазами.** Деталь, которая открылась, —
   ещё не правильная деталь ([20-02](20-02_проверка_модели.md)).
5. **Сборку сохранить ДО вставки компонентов** и открыть детали через
   `sw.preload` — иначе `AddComponent5` вернёт None
   ([30-03](../30_ГРАБЛИ/30-03_SaveAs_флаг_копии.md),
   [10-04](../10_API/10-04_сборки.md)).
6. **Никогда не выдавать непроверенное за проверенное** — ни в коде, ни в
   отчёте, ни в базе знаний.

## Состав библиотеки

| Модуль | Что в нём |
|---|---|
| `conn` | подключение, `prop`, `call`, `byref`, `select`, открытие и закрытие |
| `part` | шаблоны, плоскости, `Sketch`, `extrude`, `cut`, материалы, `save_as`, габариты |
| `assembly` | три способа расстановки, сопряжения, статусы, матрицы |
| `views` | стандартные виды, явная ориентация, снимки |
| `export` | STEP, IGES, STL, PDF, пакетный экспорт |
| `verify` | `Report`, `check_part`, `check_assembly` |
| `materials` | своя база материалов `.sldmat` |
| `dialogs` | сторож модальных окон |

Сигнатура функции — docstring в `swkit/*.py`: он актуальнее пересказа.

## Где искать ответ

От дешёвого к дорогому: `knowledge/INDEX.md` → нужный файл базы →
docstring кода → официальное API (MCP `swapi-pilot`,
`search_solidworks_api_help`, [40-01](../40_СРЕДА/40-01_установка_и_MCP.md))
→ эксперимент, результат которого записывается в базу. При расхождении базы
с документацией верить базе: записи «проверено» подтверждены на реальном
SolidWorks ([00](../00_ПРАВИЛА.md)).

## Новый проект

Скелет — `templates/new_project/`: скопировать целиком в папку проекта,
вписать корень набора в `KIT` в начале `build.py`, заменить данные в
`params.py` ([20-01](20-01_данные_отдельно_от_построения.md)), запустить
`build.py`. Скрипт проекта переносится между машинами вместо файла модели
(40-03).

## Обновление набора по ходу работы

Набор правится во время проектирования, а не отдельным заходом:

* нашли поведение API, расходящееся с ожиданием, и разобрались — **сразу**
  запись в `30_ГРАБЛИ` по `00_ПРАВИЛА.md`, строки в `INDEX.md` и
  `CHANGELOG.md`;
* написали функцию, полезную не только этому проекту, — перенести в `swkit`;
* после любой из этих правок — коммит и `git push`
  ([40-02](../40_СРЕДА/40-02_работа_с_репозиторием.md)): знание, оставшееся
  на одной машине, для остальных не существует.

Файлы обычные, правятся как текст; перезапуск агента не нужен — правка
действует со следующего чтения. Поэтому набор сделан скиллом, а не
MCP-сервером (README, «Почему скилл, а не MCP-сервер»).
