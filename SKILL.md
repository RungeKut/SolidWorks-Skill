**Первым делом:** `git -C <корень> pull --rebase`; конфликт — разобрать до
работы; владельцу — ещё `gh pr list` (skill-skill, 40-02). Версию
SolidWorks сверить с `applies_to` записей (40-03).

```python
import sys; sys.path.insert(0, r"<корень>")
import swkit as sw
sw.utf8_console()
app = sw.app()
doc = sw.new_part(app)
with sw.Sketch(doc, sw.TOP) as sk:
    sk.rect(0, 0, 2000, 1000)
sw.extrude(doc, sk.feature, 200)
sw.check_part(doc, "Плита", expect_volume_mm3=2000*1000*200,
              expect_box_mm=[2000, 200, 1000])
sw.save_as(doc, r"<папка проекта>\Плита.SLDPRT")
```

## Железные правила

1. SolidWorks запущен **до** `sw.app()`; не запущен — запустить и ждать
   регистрации в COM, иначе поднимется второй экземпляр (40-01).
2. Миллиметры и градусы на входе `swkit`; API — метры и радианы.
3. Плоскости — индексом (`sw.TOP`), не именем: имена зависят от языка.
4. Вырез направлен обратно вытяжке: `sw.cut` — `reverse=True` (30-02).
5. Результат — числом И глазами (20-02).
6. Сборку сохранить до вставки компонентов, детали открыть `sw.preload`
   (30-03, 10-04).
7. Непроверенное не выдавать за проверенное (00).
